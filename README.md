# ESAA

This repository contains my study materials, assignments, and projects completed as a member of **ESAA (Ewha Statistic Analysis Association)**.

ESAA is an academic association focused on data analysis and artificial intelligence at Ewha Womans University. Through YB and OB activities, I studied and applied various topics in data analysis, machine learning, deep learning, and NLP.

## Repository Structure

### YB

| Folder | Description |
|---|---|
| `YB_Assignment` | Weekly assignments on data analysis and machine learning |
| `YB_Practice` | Practice exercises and hands-on implementations |
| `YB_Project` | Individual and team projects completed during YB activities |

### OB

| Folder | Description |
|---|---|
| `OB_Assignment` | Advanced assignments on machine learning and deep learning |
| `OB_Practice` | Practice exercises and model implementations |
| `OB_Project` | Projects and paper studies completed during OB activities |

- **Movie Audience Regression**  
  Regression modeling for movie audience prediction.

- **Wine Quality Classification**  
  Machine learning-based classification of wine quality.

- **Credit Card Default Prediction**  
  Binary classification for predicting credit card default risk.

### OB Projects

  Machine learning-based prediction of advertisement click-through rate.

- **Novel Author Classification**  
  NLP-based classification of novel authors using text data.

- **VGGNet Paper Review & Implementation**  
  Review and implementation of *Very Deep Convolutional Networks for Large-Scale Image Recognition*.

- **Seoul Rental Price Forecasting & Recommendation System**  
  Time-series forecasting of Seoul rental prices and development of a personalized housing recommendation system.
